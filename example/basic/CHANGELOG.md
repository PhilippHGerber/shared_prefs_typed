# Changelog

All notable changes to this example application will be documented in this file.

## 0.5.0

* Initial version of the example application.
* Demonstrates core features of `shared_prefs_typed` v0.5.0.
* Includes UI examples for synchronous preference access (`main.dart`, `theme_example.dart`).
* Includes comprehensive unit tests for both synchronous (`AppPreferences`) and asynchronous (`AsyncPrefs`) generated code.
* Adds a widget test (`widget_test.dart`) to showcase testing UI components that depend on the preferences service.
